# Metrics Quick Reference

## 📊 Publisher Metrics (Port 8001)

### Pipeline Flow Metrics
| Metric | Type | Description | Labels |
|--------|------|-------------|--------|
| `pipeline_record_processing_total` | Counter | Total records processed | `stage="publisher"` |
| `publisher_csv_rows_injected_total` | Counter | CSV rows written to temp stream | - |
| `publisher_current_tps` | Gauge | Real-time transactions per second | - |

### NATS Metrics
| Metric | Type | Description | Labels |
|--------|------|-------------|--------|
| `publisher_nats_messages_published_total` | Counter | Messages published to NATS | `topic` |
| `publisher_nats_publish_errors_total` | Counter | NATS publish failures | `topic`, `error_type` |
| `nats_connection_status` | Gauge | Connection status (1=up, 0=down) | `component="publisher"` |

### Performance Metrics
| Metric | Type | Description | Labels |
|--------|------|-------------|--------|
| `publisher_io_wait_duration_seconds` | Histogram | File operation latency | `operation` (read/write/append) |
| `publisher_buffer_lag_seconds` | Gauge | Writer vs reader time lag | - |

### Health Metrics
| Metric | Type | Description | Labels |
|--------|------|-------------|--------|
| `pipeline_component_uptime_seconds` | Gauge | Component uptime | `component="publisher"` |
| `pipeline_component_errors_total` | Counter | Error count | `component="publisher"`, `error_type` |
| `pipeline_component_memory_usage_bytes` | Gauge | Memory usage in bytes | `component="publisher"` |

## 🔍 Common PromQL Queries

### Publisher Queries

**Current TPS:**
```promql
publisher_current_tps
```

**Average TPS over 5 minutes:**
```promql
rate(pipeline_record_processing_total{stage="publisher"}[5m])
```

**NATS publish success rate:**
```promql
rate(publisher_nats_messages_published_total[5m]) 
/ 
(rate(publisher_nats_messages_published_total[5m]) + rate(publisher_nats_publish_errors_total[5m]))
```

**95th percentile IO latency:**
```promql
histogram_quantile(0.95, rate(publisher_io_wait_duration_seconds_bucket{operation="append"}[5m]))
```

**Memory usage (MB):**
```promql
pipeline_component_memory_usage_bytes{component="publisher"} / 1024 / 1024
```

### Enrichment Queries

**Match success rate:**
```promql
rate(master_match_success_total[5m]) 
/ 
(rate(master_match_success_total[5m]) + rate(master_match_fail_total[5m]))
```

**Total volume processed (per minute):**
```promql
rate(enrichment_total_volume_processed[1m])
```

**Average credit score:**
```promql
enrichment_average_credit_score
```

**Bounced transaction rate:**
```promql
rate(enrichment_bounced_events_total[5m])
```

### Dispatcher Queries

**Leads per minute by type:**
```promql
rate(dispatcher_leads_generated_total[1m])
```

**Lead rejection breakdown:**
```promql
sum by (reason) (rate(dispatcher_lead_rejections_total[5m]))
```

**Cooldown effectiveness:**
```promql
rate(dispatcher_cooldown_filter_hits_total[5m]) 
/ 
(rate(dispatcher_leads_generated_total[5m]) + rate(dispatcher_cooldown_filter_hits_total[5m]))
```

**Lead generation latency (95th percentile):**
```promql
histogram_quantile(0.95, rate(dispatcher_lead_latency_seconds_bucket[5m]))
```

### Pipeline-Wide Queries

**Processing rate at each stage:**
```promql
rate(pipeline_record_processing_total[1m])
```

**End-to-end latency by stage:**
```promql
histogram_quantile(0.95, rate(pipeline_end_to_end_latency_seconds_bucket[5m]))
```

**NATS queue health:**
```promql
nats_queue_depth
```

**All component uptimes:**
```promql
pipeline_component_uptime_seconds
```

## 📈 Metric Interpretation Guide

### ✅ Healthy Values

| Metric | Healthy Range | Action if Outside Range |
|--------|---------------|-------------------------|
| `publisher_current_tps` | 18-22 | Check CSV streamer, adjust TPS |
| `master_match_fail_total` rate | < 5% | Update master data, check IDs |
| `enrichment_average_credit_score` | 300-850 | Verify calculation logic |
| `publisher_io_wait_duration` (p95) | < 50ms | Check disk performance |
| `nats_queue_depth` | < 100 | Scale consumers, check processing |
| `dispatcher_lead_latency` (p95) | < 10s | Optimize rule evaluation |

### 🚨 Alert Thresholds

| Alert | Threshold | Duration |
|-------|-----------|----------|
| Publisher Flatline | < 1 TPS | 1 minute |
| Low TPS | < 18 TPS | 2 minutes |
| High IO Latency | > 50ms (p95) | 3 minutes |
| NATS Disconnected | status = 0 | 30 seconds |
| High Orphan Rate | > 5% | 3 minutes |
| Lead Flood | > 100/min | 2 minutes |
| Pipeline Stalled | Stage delta | 2 minutes |

## 🔧 Debugging Checklist

### Publisher Issues
- [ ] Check `publisher_current_tps` - Is it 0?
- [ ] Check `nats_connection_status` - Is it 0?
- [ ] Check `publisher_nats_publish_errors_total` - Are errors increasing?
- [ ] Check `publisher_io_wait_duration` - Is IO slow?
- [ ] Check component logs for exceptions

### Enrichment Issues
- [ ] Check `master_match_fail_total` rate - Too many orphans?
- [ ] Check `enrichment_processing_duration` - Is it slow?
- [ ] Check `enrichment_average_credit_score` - Is it abnormal?
- [ ] Check NATS consumer lag
- [ ] Verify master data freshness

### Dispatcher Issues
- [ ] Check `dispatcher_leads_generated_total` - Any leads?
- [ ] Check `dispatcher_lead_rejections_total` - Why rejecting?
- [ ] Check `dispatcher_cooldown_filter_hits_total` - Too aggressive?
- [ ] Check lead thresholds in config
- [ ] Verify downstream NATS topics

### Pipeline-Wide Issues
- [ ] Check `pipeline_record_processing_total` for all stages
- [ ] Check `nats_queue_depth` - Backlog building?
- [ ] Check `pipeline_end_to_end_latency` - Too slow?
- [ ] Check component memory usage - Leaks?
- [ ] Check system resources (CPU, disk, network)
